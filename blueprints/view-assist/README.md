## View Assist Blueprints

### Dice Roller

A blueprint and pyscript for rolling dice with View Assist with an optional sound file to go along with it.

To use:
1. Import the blueprint in Home Assistant
   + Blueprint import url: https://github.com/iamjoshk/home-assistant-collection/blob/main/blueprints/view-assist/view-assist-roll-die.yaml
3. Download and move the `roll_dice.py` pyscript to the `config/pyscript` directory
4. Optionally download the `dice_roll.wav` and/or `dice_roll_boost.wav` for an audio sound effect. Move the file to your media directory or other accessible location.
5. Create a new automation using the blueprint.
6. May the virtual math rocks be in your favor.
